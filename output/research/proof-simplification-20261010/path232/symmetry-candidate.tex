\paragraph{Cycles constructed from middle-colour grids.}
The subgraph with fixed middle colour $c$ is the grid
$K_{[4]\setminus\{t_0,c\}}\square
 K_{[4]\setminus\{t_2,c\}}$.
Use the following cycles, with coordinates $uvw$:
\[
\begin{array}{c|l}
001&120\ 123\ 323\ 313\ 213\ 210\ 230\ 130\ 132\ 232\ 212\ 312\ 310\ 320\\[2pt]
010&101\ 121\ 321\ 323\ 123\ 103\ 303\ 302\ 301\\
   &201\ 203\ 202\ 102\ 132\ 232\ 231\ 131\\[2pt]
012&131\ 101\ 103\ 203\ 303\ 301\ 201\ 231\\
   &230\ 130\ 120\ 123\ 323\ 320\ 321\ 121
\end{array}
\]
For $001$, start with the middle-$1$ grid cycle
$310,313,213,210,212,312$ and the two middle-$2$ and
middle-$3$ square cycles. Splice them along the equal-assignment
edges $310$--$313$ / $320$--$323$ and
$210$--$212$ / $230$--$232$.

For $010$, start with the middle-$0$ grid cycle
$101,102,202,203,201,301,302,303,103$ and the two squares.
Splice along $101$--$103$ / $121$--$123$ and
$101$--$102$ / $131$--$132$.
The unused-colour swap $2\leftrightarrow3$ reverses the first
cycle and exchanges its two square attachments, so it preserves
the resulting edge set. The middle-$2$ and middle-$3$ retained
square paths are respectively
$121,321,323,123$ and $132,232,231,131$.

For $012$, use the middle-$0$ cycle
$101,103,203,303,301,201$, its image under path reversal and
$0\leftrightarrow2$ in the middle-$2$ grid, and the middle-$3$
square. Splice along $101$--$201$ / $131$--$231$ and
$121$--$120$ / $131$--$130$.
Path reversal followed by $0\leftrightarrow2$ exchanges the first
two grids and preserves the square and its two attachments, hence
preserves the resulting cycle. All three constructions splice a
tree of three grid cycles, so they are Hamilton cycles.

Allow all colour images and path reversals as before. A labelled
end-change boundary has one allowed edge set, a middle-change
boundary has two, and an all-distinct boundary has one.
The end-change square-support properties are unchanged, and each
middle-change cycle still retains three edges in both supported
bad squares. Thus the bad-block construction retains all its
hypotheses.

\paragraph{Twenty safe-interface witnesses.}
Number source-cycle edges cyclically from one in the displayed words.
For an end-change target, map $(0,1,2,3)$ to $(a,b,h_0,h_1)$,
where $a$ is repeated, $b$ is the singleton and $h_0<h_1$ are unused;
reverse the path when the singleton is at its left end.
For a middle-change target $(a,b,a)$ use the same colour map;
columns $0,1$ mean without and with path reversal. Swapping
$h_0,h_1$ changes no edge set. For an all-distinct target $(a,b,c)$,
use the colour map $(a,b,c,d)$, where $d$ is unused; the two possible
path orientations give the same edge set.

\paragraph{Limits of the simplification.}
The twenty entries are still a finite local certificate, not a
type-free analytic inequality. In particular, intersecting the
edges common to all allowed cycles at each boundary cannot supply
the two interface edges: for boundaries $001$ and $101$, that
intersection contains no common safe edge, although each individual
pair of chosen cycles has at least two.
Nor can the middle-change family be reduced to one edge set while
retaining all path-reversal images. Reversal fixes seven vertices
of $B_{010}$ and moves others; a nonidentity automorphism of a
$17$-cycle fixes at most one vertex. Hence no Hamilton cycle of this
fibre can be invariant under path reversal.
