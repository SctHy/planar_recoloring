## Mathematical sufficiency

For a finite simple graph H, a Hamilton cycle through v uses two distinct edges incident with v. If S is a set of protected H edges and d_(H−S)(v) ≤ 1, every such cycle uses at least one S edge incident with v. More generally it uses at least max(0, 2−d_(H−S)(v)) such edges. This is conditional on a Hamilton cycle of the target component containing v; no Hamilton-cycle existence or target-pool retention assumption is needed for the inference.

Here the source hard set is K = D minus its source pool. The main's thirteen literal ports and two-edge pools give eleven K edges for each hard source. Take S = (K ∩ E(H)) minus the prescribed restored target pool. If an arbitrary target Hamilton cycle C meets S, this is an edge in both K and C minus that pool. In particular it is a protected common edge for the manuscript's selected target cycle.
