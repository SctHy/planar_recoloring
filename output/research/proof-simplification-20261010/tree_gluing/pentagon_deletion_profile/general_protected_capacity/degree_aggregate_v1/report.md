# 低度缺口聚合：有效条件界，但局部优化没有额外覆盖

数学条件界成立：S 为共同状态中目标度不超过三的状态集，A=Σ(4−d_t)，B 为源圈可能通向共同集之外的边数上界，加两池并集在 S 的共同合法边关联数。源 Hamilton 圈在每个 S 状态取两条边；设其中丢失 ℓ 条，目标圈至多避开 d_t−2 条合法源安全边。共同安全关联数至少 Σ(4−d_t−ℓ)，而 Σℓ≤B，每条公共边被计至多两次，得到 max(0,ceil((A−B)/2))。证明不使用选定的源、目标圈边集。

程序只将完整已核验的 C1/FHC 字串当成无序状态集；池按原固定边集读回。对230个普通双圈接口生成局部单坐标邻居，没有构造完整状态图或搜索 Hamilton 圈。全部低度共同状态作 S 时，97/230 的界为正，最大保证五条共边。典型00101的坐标0改为1，40个共同状态中仅两个目标度三的状态；它们各有一条可能通向圈外的边，A=B=2，界为零，不会与已有只共享三条边的任意圈例冲突。

独立数学审查发现该聚合在当前单坐标接口中可精确还原为逐顶点界：每个圈外状态在编辑坐标最多有两个共同邻居，所以 |E(S,O)|≤2|O|，B 的 min 总取图切边数。设 d_s,d_t 为两侧度，d_c 为共同邻边数，f 为两池并集中的共同邻边数，则一个状态的有符号贡献为 4−d_s−d_t+d_c−f。因而全 S 的97覆盖会被只选正贡献状态的局部优化包含；独立分支核验优化覆盖125/230。本聚合在这些接口上不产生超过125的新覆盖。

该关系说明一种应停止重复的方向：再对同一全部低度状态求和或打印相同切边表，不能提高局部准则。更强方法须使用单坐标邻接之外的结构约束、圈的连通性或可证明的符号选择规则。

实际 Python3.14.6，236480次局部颜色选项检查，约0.040秒。97和125均是固定完整列表图与池上的有限覆盖；条件不等式是解析证明，覆盖正性尚不是统一符号族定理。源或目标为困难 D 端口的接口不具备两侧完整 Hamilton 圈前提，本分支全部排除。
