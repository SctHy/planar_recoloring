\paragraph{Four hard--hard interfaces by weak port transport.}
Let $g$ be the prescribed map from an adjacent boundary to its
representative. A named port $e\in K_s$ with $g(e)\in K_t$
already gives $e\in K_s\cap g^{-1}(K_t)$; this uses no
Hamilton-cycle hypothesis or whole-template equivariance.
All memberships below include exclusion from the displayed pools.

For $00001$, changing coordinate $4$ to $2$ or $3$ gives the
colour maps $p_2=(12)$ and
$(p_3(0),p_3(1),p_3(2),p_3(3))=(0,2,3,1)$, with no coordinate
change. The fixed target port $f=13120\!-23120$ has respective
inverse images $13210\!-23210$ and $12310\!-32310$.
All three ports belong to the displayed $K_{00001}$.

For $00112$, the changes $(j,q)=(0,2)$ and $(3,2)$ have maps
\[
 \lambda(w)_i=(02)(w_{-i}),\qquad
 \mu(w)_i=(12)(w_{1-i})\qquad(i\bmod5).
\]
They send the following named protected ports to protected ports:
\[
 \lambda(12023\!-13023)=13020\!-13023,\qquad
 \mu(13030\!-13230)=32030\!-32031.
\]
Both maps are involutions and swap their displayed port pairs.
These four ports belong to $K_{00112}$, so one designated source
port suffices for each of the two interfaces. No induced joint
support graph is required.

These four prescribed-map certificates complete the four residual
case identities after the previously retained forty-nine mixed
degree/weak-transport cases. The resulting fifty-three-case union
uses those distinct mechanisms and their existing pool/map premises;
it is not a single symbolic classification of all hard interfaces,
nor a statement about arbitrary hard protected sets or normalizers.
