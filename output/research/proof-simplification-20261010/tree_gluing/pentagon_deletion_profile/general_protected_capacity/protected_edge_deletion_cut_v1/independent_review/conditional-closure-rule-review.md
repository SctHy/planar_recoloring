# Necessary conditional Hamilton-cycle closure rules

This file reviews the general rule mathematically. It does not independently certify the six additional case traces supplied by root, and none of those six is counted as an independent PASS here. Only the four bridge-cut certificates in four-cut-results.json were independently recomputed from actualsource.

Suppose a Hamilton cycle C avoids the safe oppositefixedK edges. Let A initially be the remaining graph edge set and let R initially be empty. Maintain the necessary invariant R subset C subset A. Every vertex must have exactly two C-incident edges.

If the A-degree of a vertex is below2, no such C exists. If its R-degree exceeds2, no such C exists. If its A-degree equals2, both incident A-edges must belong toC and may be added toR. If its R-degree equals2, every other incident edge must be excluded fromC and may be removed fromA. Repeating these rules preserves the invariant. A required edge removed fromA is also a contradiction; an implementation must preserve/check R subset A rather than silently dropping a required edge during simultaneous updates.

A cycle already wholly contained inR is a contradiction only if it is proper, with fewer vertices than the full component. Its vertices already have their two cycle edges, so C cannot connect them to the remaining vertices. A spanning R-cycle is not a contradiction. Likewise a triangle is not automatically invalid: the relevant question is whether it is a proper forced cycle in this wholecomponent problem.

The rules are necessary conditions, not a complete Hamiltonicity decision method. Their failure to yield a contradiction is inconclusive. Their use is conditional on avoiding the actual safe fixedK edge set in the originalinterface map/pool coordinates; old intrinsic closures on the undeleted graph do not substitute for that condition. The resulting universal claim quantifies only the HC on this side, with the oppositeK fixed. Specified pool/reserve containment needed by global gluing remains inherited.
