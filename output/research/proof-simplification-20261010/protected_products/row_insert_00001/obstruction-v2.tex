% Stronger obstruction: it applies to every possible two-row seed while
% preserving the original K12, not only to the printed seed.
\paragraph{Keeping the original protection forbids every matching insertion.}
Let $X,Y$ be the twenty/twenty-four sign classes of the $00001$
component. The set $X$ is independent, and the only edges within $Y$
are $12312\,12313$ and $13212\,13213$.
Suppose a matching $M$ is cut from the row of any two-row seed to be
extended, and the new row is a spanning nonisolated linear forest $L$
with endpoint set $V(M)$. Write $t,r$ for the numbers of $XY$ and $YY$
edges of $M$, and $q$ for the number of $YY$ edges of $L$.
There are $t$ endpoints in $X$ and $t+2r$ in $Y$. Subtracting the
two new-row degree sums gives
\[
(48-t-2r)-(40-t)=2q,\qquad\text{so }r+q=4.
\]
Since $r,q\le2$, both equal two. Thus $M$ must cut both $YY$ edges,
and $L$ must contain both. Their four endpoints all have degree one
in $L$, so $12313$ is joined only to $12312$.
But the original protected set contains $12313\,12323$.
This contradicts retaining that edge in the new row.
Therefore no choice of two-row seed, matching cuts or reserve edges
can realize this insertion while retaining the original protected set.
