# 一般平面围长五图四色 Hamiltonicity 的前沿研究

本轮研究回答一个问题：现有正文能否沿"保护五边形"路线推进到
`h(P_5) = 4`。结论是：可以前进一步——把 Δ≥4 的 block 归约到"五圈上至多一个
高度数顶点"的局部类型；但精确有限计算显示，这一局部类型本身已经出现
**没有 Hamilton 圈的分量**，因此现有附件证书机制不能直接延拓。`h(P_5) = 4`
仍然开放，本轮不修改正文或附件。

## 1. 现状

- 正文证明 `4 <= h(P_5) <= 5`，并解决两个子类（至多 7 个不同 5-圈；每个
  block 最大度 ≤ 3）。
- 文献检索（2026-10-12）没有找到一般 P_5 四色 Hamiltonian 的解决或反例。
  目前对一般 P_5 最强的已发表结果是 Bartier–Bousquet–Feghali–Heinrich–
  Moore–Pierron（SIDMA 2023）的四色连通性；本文把它加强到两个子类的
  Hamiltonicity，但没有解决一般情形。
- 正文第 6 节给出的一般边界：最小反例必含一个"block 内部最大度 ≥ 4"的 block。

## 2. 现有证明留下的精确缺口

最小反例经过正文的归约后满足：没有度 ≤ 1 的顶点；没有相邻二度点；任意两个
二度点要么距离 ≤ 2，要么邻域相交；没有 (2,3,2) 路径；没有 Δ ≤ 3 的 block。
于是必须处理一个 2-连通 block `B`，`Δ(B) >= 4`。正文的 block-subcubic 证明在
`Δ(B) <= 3` 时用五面恒等式找到避开 cutvertex 的五边形并调用"两个分离五边形"
恢复引理；`Δ(B) >= 4` 时该计数不再直接给出干净五边形。

## 3. 新结构引理（解析，待独立审读）

沿用正文的五面恒等式（第 5.1 节）：对连通平面围长 ≥ 5、最小度 ≥ 2 的图，
设 `p` 为 5-面数，`Q = Σ_{|F|≥7}(|F|-6)`，`s` 为二度点数，
`D = Σ_{d(v)≥3}(d(v)-3)`，则

```
p = 12 + Q + 2D - 2s.
```

**引理（一个高度数顶点的五面）** 设 `B` 是围长 ≥ 5 的 2-连通平面图，
`Δ(B) >= 4`，`x ∈ V(B)`，`H = {v : d_B(v) >= 4}`。若

- `d_B(x) <= 3` 时 `2s + d_B(x) < 12 + Q`，或
- `d_B(x) >= 4` 时 `2s < 6 + Q + d_B(x)`，

则存在 5-面 `F`，`x ∉ F` 且 `|F ∩ H| <= 1`。特别地，`s = 0` 时条件恒成立。

证明要点：坏面 = 含 `x` 的面（至多 `d_B(x)` 个）∪ 含至少两个 `H∖{x}` 顶点的
面。若 `H' = H∖{x}`，双重计数给出这些面的数目至多
`d_B(x) + ½Σ_{v∈H'}d_B(v)`；又 `Σ_{v∈H'}d_B(v) = 3|H'| + D' <= 4D'`
（`D' = Σ_{H'}(d-3)`）。代入五面恒等式后，两种情形分别得到
`p - #坏面 >= 12 + Q - 2s - d_B(x)`（`x` 不在 `H`）与
`6 + Q + d_B(x) - 2s`（`x` 在 `H`），由假设为正。候选 LaTeX 见
`counting-lemma-candidate.tex`。

**对最小反例的推论**：若最小反例含一个无二度点、内部 Δ≥4 的 endblock，
则其中存在一个避开 cutvertex、且至多含一个内部度数 ≥4 顶点的 5-面。面上其余
顶点度数恰为 3，即局部边界是"一个大小 ≥2 的色表 + 四个恰三色表"。对两个不同
endblock 分别应用该引理（另一个 endblock 若 Δ≤3 则由正文的计数给出干净五边形），
就得到正文"两个分离五边形"恢复引理所需的两条互不相邻 5-圈，只是其中一条的
局部边界可能带一个 2-表。

## 4. 局部 C5 色表纤维的精确计算

模型：边界 `t = (L_0,…,L_4)`，`L_i ⊆ {0,1,2,3}` 非空；局部纤维 `F(t)` 为
`C_5` 的正常染色 `x_i ∈ L_i`，单点改动连边。三色表对应圈上度 3 顶点，二色表
对应度 4 顶点（两个外部邻居），一色表对应度 5 顶点。所有计算在
`pentagon_boundary_fibres.py`，结果在 `pentagon-boundary-report.json`。
对称群为 `D_5 × S_4`（240 阶）。分量 Hamilton 圈/路：≤18 个状态用固定起点
子集 DP 精确判定；更大分量先用确定性 Warnsdorff 搜索，再用带步数上限的
剪枝 DFS（DFS 的剪枝只使用必要条件，因此完整搜索返回的否定是精确的）。

| 边界类 | 带标号边界 | 轨道 | 无圈分量轨道 | 无路分量轨道 | 空纤维轨道 | 单点分量轨道 | 未决轨道 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 每表 ≥3 色（正文附件模型） | 3,125 | 36 | 0 | 0 | 0 | 0 | 5 |
| 一个 2-表 + 四个 3-表 | 7,680 | 44 | 9 | 2 | 0 | 1 | 7 |
| 一个 2-表 + 其余 3/4-表 | 18,750 | 111 | 9 | 2 | 0 | 1 | 23 |
| 一个 1-表 + 四个 3-表 | 5,120 | 31 | 11 | 4 | 0 | 1 | 0 |
| 每表 2 或 3 色 | 100,000 | 527 | 291 | 74 | 1 | 53 | 20 |
| 每表 2–4 色且至少一个 2-表 | 157,926 | 847 | 337 | 86 | 1 | 53 | 55 |

关键读数：

1. **回归**：每表 ≥3 色（现有附件的世界）没有空纤维、单点分量或已证实无圈
   分量；5 个轨道的分量超过 18 个状态、搜索未完成，正文明印了这些类型的圈。
2. **单高度数顶点已经足够破坏"分量圈"**：一个 2-表 + 四个 3-表的 44 个轨道
   中有 9 个含无 Hamilton 圈的分量（1,440/7,680 个带标号边界，18.75%）。
   其中 7 个轨道的坏分量有割点（割点图不 Hamiltonian，可显式复核）；另 2 个
   （29、31 个状态的无割点分量）由穷尽剪枝搜索判定为无圈。
3. **路径比圈活得久**：上述 9 个坏圈轨道里只有 2 个连 Hamilton 路都没有；
   "分量路块 + 拼接"（正文对 00001/00112 用的机制）比"分量圈 + pool"更有
   延拓空间。
4. **一色表更糟**：一个 1-表（度 5 顶点）+ 四个 3-表的 31 个轨道里有 11 个
   无圈、4 个无路。
5. **空纤维很罕见**：在色表 ≥2 的世界里，空纤维恰好只有一类——五个位置都是
   同一个二色表（1 个轨道，6 个带标号边界），对应五边形五个顶点度 ≥4 且可用
   颜色全部相同的退化情形。
6. **单点分量可救**：唯一单点分量轨道
   `[[0,1],[012],[023],[023],[013]]` 的单点状态 `(1,0,2,3,0)` 在每个位置都被
   邻点颜色封死；但接口探测显示它在 70 个单表改动中有 35 个仍与下一层共有，
   63 个改动有非空公共状态，所以需要的是新的分层拼接论证，而不是直接判死。

## 5. 前沿的重新表述

结合第 3、4 节，`h(P_5) = 4` 的剩余障碍是：

1. **无二度点的 Δ≥4 endblock**：已可归约到"一个大小 ≥2 色表 + 四个三色表"的
   五边形局部类型，并且对两个 endblock 各取一条，可配对成正文恢复引理需要的
   两条分离 5-圈；但该类约 1/5 的边界类型没有分量圈（多数有割点证书，少数
   需穷尽搜索）。现有附件证书不能直接套用，需要新的局部引理（优先考虑路径块
   机制，因为大部分坏分量仍有 Hamilton 路），特别是 `lem:two-pentagons-restore`
   的"至多一个 2-表"版本；单 block 情形还需要单五边形变体。
2. **block 含二度点**：第 3 节引理的一般条件
   `2s + d_B(x) < 12 + Q`（或 `x` 高度数时的另一条件）不总成立；需要新的
   归约把二度点情况单独消掉。
3. **高度数顶点的度数**：引理只保证"至多一个高度数顶点"，该顶点度可能 ≥6
   （四个外部邻居可占满四色，局部表为空）。要得到干净的 2-表，需要更强的
   结构结论或对空纤维的专门处理。
4. **tighter target**：即便 `h(P_5) = 4` 解决，`hc(P_5) = 4` 的四色
   Hamilton-connected 也需要端点保留版本的全部局部机制，距离更远。

建议的下一步：(i) 把第 3 节引理写成正式命题并做独立数学审读；(ii) 在
"一个 2-表 + 四个 3-表"类上设计路径块版本的恢复引理，先处理 7 个有割点证书
的坏轨道；(iii) 对无割点的 2 个坏轨道寻找短的结构性否定证书（小割集或
Chvátal 型独立集证书）；(iv) 研究二度点存在时的计数或归约。
